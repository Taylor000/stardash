# 任务记录实施计划

用户已指定：顶部“分类与标签”后增加“任务记录”。沿用个人版直接实施、验证和部署的授权，不增加确认轮次。

设计：新增登录后可访问的 `/tasks` 页面，读取现有批量取消收藏记录，展示创建/更新时间、状态和数量；展开后按项目展示结果和错误。支持历史与项目明细分页，已完成任务持续可查。只读现有记录，不创建新任务、不触发 GitHub 写入、不改变数据库结构。普通分类/标签操作当前没有历史数据，不补造记录。

实现方式：独立页面比收藏库内弹窗更便于随时返回；独立只读接口避免影响现有后台执行和进度轮询。沿用现有浅色组件与账号认证。所有查询必须限定当前用户，详情仅返回项目名称、GitHub ID、状态、尝试次数和错误，避免返回备注等完整快照数据。
